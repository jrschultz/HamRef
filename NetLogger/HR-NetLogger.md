# 🗃️ HAMREF - 🪵 NetLogger

Net Logger is a slick self contained web page for logging contacts during a net. 

It was customized for the 🫎 [Moose Jaw Amateur Radio Club](https://mjarc.ca/) from [this repo](https://github.com/po468/EC-code).

It has an accompanying ```generate-net-pdf.py``` script that converts the exported ```.json``` net check-in data into a nice PDF file for archiving. 

Run the script with the following:

```bash
python3 generate-net-pdf.py ExportedNetData.json -o ExportedNetData.pdf
```
