Good evening to all. This is the Moose Jaw Amateur Radio Club 2 Meter Net. This net meets daily at 0300 UTC on the VE5CI repeater for the purpose of passing traffic, bulletins, or other items of interest to radio amateurs in the Moose Jaw area.

Your net manager is _____ (name & call) and your net controller for this evening is _____ (name & call).

 🔺Do we have any stations with emergency or priority traffic?

Settings

QRZ.com XML Data subscription is optional. When enabled, Tab (or leaving the callsign field) looks up new callsigns automatically. Callsigns already in the roster are filled from stored data instead. Browser CORS often blocks QRZ; Callook.info is used as a free fallback for US callsigns.

How to use MJARC Net Logger

Quick start

  1. Enter the Net Control Station (NCS) callsign first and press Enter or + Add.
  2. Click ▶ Start Net (enabled only after the first check-in).
  3. Add more stations the same way. Click ■ Stop Net when finished (auto-exports a JSON file).

Entering callsigns

  • Partial match: Type part of a call (e.g. STZ) — matching roster entries appear as chips under the form and the right-side roster filters. Click a chip (or press Enter if only one match) to add it immediately.
  • Tab / blur: If the call is already in the roster, Name / Location / Comment fill from stored data. If it is new, a lookup runs (QRZ if configured, otherwise Callook for US calls).
  • Enter in any of the four fields (Callsign, Name, Location, Comment) adds the check-in.
  • Duplicate callsigns in the same net are blocked.

QRZ login

Click ⚙ Settings in the header. Enter your QRZ username and password (XML Data subscription recommended). Credentials stay only in this browser. If QRZ is blocked by the browser, Callook.info is used automatically for US callsigns. Use the 🔍 button anytime for a manual lookup.

Editing the check-in list

  • Click any field (callsign, name, location, comment) to edit it in place. Press Enter or click away to save; Escape cancels.
  • Move to — type a line number next to an entry to reorder it. Line 1 is always NCS.
  • Checkbox on the left = acknowledge the check-in. Use Clear Acks in the roster header to reset all.
  • ✕ deletes an entry.

Roster (right panel)

  • Automatically stores stations from every check-in.
  • Click a roster entry to add it straight to the current net.
  • ⬆ Roster only imports names from a previous export without loading a whole net.

Tips

  • Total time = elapsed net time × number of check-ins (shown as hours + minutes and total minutes).
  • Export / Import keep your net and roster. Data is stored only in this browser — export regularly.
  • Theme toggle (🌓) switches light / dark mode.
  • Use the Net Script tab for the MJARC 2 meter net preamble, check-in order, and close.
